# Grok Bot Game（Godot 4 原型）

直向 1080×1920、單指點擊的兩個小遊戲：**D 抽層**、**E 相位咬合**。
僅使用 Tween 與色塊幾何，沒有物理、沒有齒輪網格、沒有執行期 CSG。

## 如何用 Godot 4 開啟

1. 安裝 **Godot 4.3**（4.3.x 皆可；渲染器為 GL Compatibility）。
2. 開啟 Godot → **Import**／匯入 → 選本資料夾裡的 `project.godot`。
3. 主場景已設為 `Boot.tscn`，按 **F5**（執行專案）即可。
4. 若要單獨跑某一模式：開啟對應 `.tscn` 後按 **F6**（執行目前場景）。

視窗預設為 1080×1920，伸縮模式 `canvas_items`、長寬比 `keep`。桌面預覽另設 540×960 覆寫，畫面仍依 1080×1920 繪製。

## 場景對照

| 檔案 | 用途 |
|------|------|
| `Boot.tscn` + `Boot.gd` | 開機選單。兩個按鈕：**D**、**E**。 |
| `ModeD.tscn` + `ModeD.gd` | 模式 D 抽層（Pull Layer）。 |
| `ModeE.tscn` + `ModeE.gd` | 模式 E 相位咬合（Phase Snap）。 |

失敗或 90 秒到時會出現全螢幕覆層，**再點一下會重開同一個場景**（沒有暫停）。

## 操作（單指點擊）

- 桌面：滑鼠左鍵。行動裝置：單指點按。
- **D**：依點擊的 **Y 座標**對到六條橫帶（不做 raycast）。點鬆層滑出；點裂層則倒塌結束。Tween 進行中不接受點擊。
- **E**：點擊全螢幕，取當下圓盤旋轉角，與最近窗口中心比角度。

## Inspector 可調參數

在編輯器選取場景根節點即可改帶高、±12／±28、轉速等 `@export`。

Tripo 三件（`d_slab`、`d_slab_crack`、`e_gear`）後補。
