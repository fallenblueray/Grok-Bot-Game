# Grok Bot Game (Godot 4)

A portrait 1080×1920 prototype. **A is the game:** a multiplier-gate runner with levels 1, 4, and 8.

## Run

1. Install Godot 4.7.
2. Import `project.godot` and press **F6** or **F5**.
3. Select **A**, or press `A` / `1`.

## Play on Pages

Open the GitHub Pages build, choose **A**, and drag left or right to move the swarm through the gates. Tap after a clear to advance or after a failure to retry.

The optional **E** mode remains available from the menu.
